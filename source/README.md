# GREEN HAVEN — Махалля будущего

Интерактивная презентация из 14 сцен для СОР-1, 10 класс: «Воспитание» и «Основы государства и права», Узбекистан. Сцены 1–2 сохраняют исходные изображения, типографику, оформление и GSAP-анимации.

## Запуск готовой версии без интернета

Распакуйте весь GREEN-HAVEN.zip, запустите START-GREEN-HAVEN.cmd и оставьте окно сервера открытым. Адрес: http://localhost:4173. На другом компьютере заранее установите Node.js. Установка npm-пакетов для показа не нужна. Можно запустить вручную: node server.cjs --open.

Все изображения, шрифты, стили и скрипты локальные. Содержание источников кратко изложено внутри презентации; только переход к оригиналам LexUZ и ВОЗ требует интернета. Не открывайте index.html двойным щелчком: используйте локальный сервер.

## Разработка

В папке source: pnpm install, затем pnpm dev. Адрес разработки http://localhost:3000. pnpm build создаёт статический сайт в out/. Для первоначальной установки зависимостей нужен интернет. Технологии: Next.js App Router, TypeScript, Tailwind CSS 4, GSAP.

## Управление

- ← / →, Page Up / Page Down, пробел — смена сцен. Клавиши редактирования в полях не переключают сцену.
- «Все сцены» — меню; точки прогресса и нижние стрелки — переходы.
- F или кнопка в шапке — полный экран; Esc — выход. Если браузер ограничивает API, используйте F11.
- Сцена 2: ползунок мышью, касанием или стрелками при фокусе.
- Сцены 5 и 13: редактируемые поля; данные сохраняются в localStorage этого браузера. «Скачать мои записи» экспортирует JSON. Автоматического импорта нет; копия пригодна для хранения и ручного восстановления.
- Сцены 8–9: выбор решения; 11: четыре зоны плана; 12: шесть этапов года.
- «Источники» открывают локальные пояснения с названиями документов, статьями и официальными ссылками.

## Содержание и честность данных

Факты отделены от проектных предположений. Никаких выдуманных опросов, результатов наблюдений, бюджетов и достигнутых показателей. Поля личного вклада и наблюдений оставлены пустыми. План на 365 дней условен: сезон, согласования, ответственные и ресурсы уточняются на месте.

Все шесть изображений — концептуальные визуализации вымышленной махалли, созданные ImageGen, а не фотографии реального объекта. До/после сохраняют один ракурс. Схема махалли без масштаба и не предназначена для строительства.

## Проверки

Производственная сборка Next.js и TypeScript успешна. Все 14 сцен проверены в браузере при 1280×720: нет горизонтальной прокрутки, сломанных изображений и текста за границами сцены. Основные композиции просмотрены также при 1440×810. Проверены навигация, исходный ползунок, окна источников, четыре зоны, шесть этапов, вкладки и сохранение поля после перезагрузки. Ошибок и предупреждений в консоли при проверке не обнаружено.

Исходные базовые стили globals.css и файлы after.webp/before.webp сохранены. Дополнительные стили вынесены в extended.css; содержимое новых сцен — ExtendedScenes.tsx; источники — sources.ts.
