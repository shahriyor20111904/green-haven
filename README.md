# GREEN HAVEN — Махалля будущего

Интерактивная веб-презентация учебного проекта о махалле будущего в Узбекистане. В 14 сценах представлены концепция благоустройства, экологические решения, участие жителей и условный план действий. Иллюстрации концептуальные; проект не является строительной документацией.

Репозиторий подготовлен для задания PROWEB «Проект на GitHub».

## Возможности

- Навигация по сценам стрелками, пробелом и через меню.
- Интерактивное сравнение «до / после».
- Выбор решений, просмотр зон махалли и этапов плана.
- Полноэкранный показ, пояснения и ссылки на источники.
- Локальное сохранение пользовательских записей в браузере и экспорт JSON.

## Быстрый запуск готовой версии

Нужен Node.js. Дополнительные пакеты не требуются.

```sh
node server.cjs
```

Откройте **http://localhost:4173**. Чтобы остановить сервер, нажмите **Ctrl+C** в его окне. После скачивания репозитория готовая презентация работает без интернета; интернет нужен только для перехода к внешним источникам.

Не открывайте `presentation/index.html` двойным щелчком: используйте локальный сервер, чтобы пути к ресурсам работали правильно.

## Разработка из исходников

Нужны Node.js 20.9 или новее и pnpm (в исходном проекте указан pnpm 10.28.2).

```sh
cd source
pnpm install
pnpm dev
```

Адрес для разработки: **http://localhost:3000**.

```sh
pnpm build
```

Команда создаёт статическую сборку в `source/out/`. Папка `presentation/` содержит ранее подготовленную сборку для быстрого показа. После изменения исходников её нужно обновить содержимым `source/out/`.

## Инструменты

- Next.js 16 и React 19 — интерфейс и статическая сборка.
- TypeScript — код приложения.
- Tailwind CSS 4 и CSS — оформление.
- GSAP — анимации.
- Node.js — локальный сервер без дополнительных зависимостей.
- Git и GitHub — история изменений и размещение репозитория.

```text

source/app/          Компоненты, сцены, данные и стили
source/public/       Локальные изображения и шрифты
```

Для проверки готовой версии запустите сервер, откройте главную страницу, переключите сцены и проверьте загрузку изображений. Сборка исходников требует отдельной установки зависимостей; для просмотра готового проекта она не нужна.
